## 4. 47번(법정동코드 `StanReginCd`) 재검증 결과 안내

전달해주신 공식 요청 스펙 그대로 아래 3가지 조합을 모두 직접 호출해 확인했습니다.
- `https://apis.data.go.kr/1741000/StanReginCd/getStanReginCdList?ServiceKey=...&pageNo=1&numOfRows=5&type=json`
- `https://apis.data.go.kr/1741000/StanReginCd/getStanReginCdList?serviceKey=...&pageNo=1&numOfRows=5&type=json`
- `https://apis.data.go.kr/1741000/StanReginCd/getStanReginCdList?ServiceKey=...&pageNo=1&numOfRows=5&type=xml`

3건 모두 게이트웨이(`apis.data.go.kr`) 단계에서 **`HTTP 403` / `SERVICE_KEY_IS_NOT_REGISTERED_ERROR (등록되지 않은 서비스키, returnReasonCode=30)`** 가 반환되었습니다.  
파라미터 오류가 아니라 **현재 `cert_key`가 해당 API(`행정안전부_행정표준코드_법정동코드`)에 아직 매핑/동기화되지 않은 상태**이므로, 공공데이터포털 마이페이지에서 해당 API 상세화면의 **일반 인증키(Encoding)** 값이 현재 `cert_key`와 동일한지(또는 다른 계정/키로 신청되었는지, 방금 승인된 경우 동기화 대기 여부) 확인해 주시면 됩니다.
